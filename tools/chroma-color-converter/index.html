Approximate · unofficial. Swatches are sRGB screen approximations compiled from public open-source datasets, not Pantone's licensed spectral data. A monitor can't reproduce ink on paper or dyed textile exactly, so treat every match as a starting point and confirm against a physical Pantone guide or Pantone Connect before you print or order. PANTONE® and other Pantone trademarks are the property of Pantone LLC. This tool is not affiliated with or endorsed by Pantone.
Notes. Every field is two-way: edit it and everything else follows. The byte-swapped box is what most ESP32 SPI panels expect — ST7789 / TFT_eSPI / Adafruit_GFX push the high byte first, so 0xA01F goes on the wire as 0x1FA0. RGB565 is lossy; the small preview tag shows the actual color the panel renders. Pantone matching runs a nearest-neighbour search in CIELAB using ΔE2000 across Solid Coated, Solid Uncoated and TCX. Type a PMS code (286 C, 286 U), a TCX code (11-4201) or a name (Cloud Dancer) into the top bar or the Pantone boxes and it snaps. Rough guide: ΔE00 under 1 is invisible, 1–2 is close, above 3–5 is a clearly different color.
